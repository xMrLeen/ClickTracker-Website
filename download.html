ClickTracker

Für Windows 10 (ab Version 2004) und Windows 11, 64-Bit.
Eine einzige Datei – alles Nötige ist dabei.

Herunterladen
Kein Installer gefunden. Setup-Datei in den Ordner website/downloads/ legen und in config.js prüfen, welche Datei eingetragen ist.

Installieren. Fertig.

Auf dem PC muss nichts vorinstalliert sein. Der Assistent spricht Deutsch, Englisch, Französisch oder Italienisch – passend zur Windows-Sprache.

Installation

  • Für alle Benutzer unter „Programme“
  • Oder „nur für mich“ – ohne Admin-Rechte
  • Startmenü-Eintrag, Desktop-Verknüpfung optional
  • Auf Wunsch Start mit Windows

Alles enthalten

  • .NET ist eingebaut
  • Vorhandenes Python ab 3.10 wird verwendet
  • Sonst wird die neueste Python-Version installiert
  • Export-Pakete kommen aus dem Installer – ohne Internet

In vier Schritten startklar.

01

Herunterladen

Die Setup-Datei über den Knopf oben speichern.

02

Ausführen

Doppelklick auf die Datei im Download-Ordner.

03

Installieren

„Für alle“ oder „nur für mich“ wählen und den Assistenten durchklicken.

04

Loslegen

ClickTracker im Startmenü öffnen und die erste Aufnahme starten.

Windows meldet „Unbekannter Herausgeber“? Das passiert, solange der Installer nicht mit einem offiziellen Zertifikat signiert ist. Auf „Weitere Informationen“ und dann „Trotzdem ausführen“ klicken. Weil ClickTracker global auf Tastatur und Maus hört, kann auch ein Virenscanner nachfragen.

Für die IT

Stille Installation.

Für Softwareverteilung wie Intune oder Software-Center. Exit-Code 0 bedeutet erfolgreich.

# für alle Benutzer (Admin)
ClickTracker-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

# nur für mich
ClickTracker-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER

# ohne Autostart
ClickTracker-Setup.exe /VERYSILENT /TASKS="!autostart"

# deinstallieren
"C:\Program Files\ClickTracker\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES

Beim Deinstallieren bleiben die eigenen Einstellungen und Anleitungen standardmässig erhalten. Python bleibt installiert, weil es ein eigenständiges Programm ist.
